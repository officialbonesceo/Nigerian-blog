# 9jaBeacon Cloudflare Worker Backend

This directory contains the standalone Cloudflare Worker for **9jaBeacon**, responsible for automated scheduled RSS ingestion, Groq AI editorial restructuring, and direct Cloudflare D1 database persistence.

## Architecture

* **Frontend:** Hosted on **Cloudflare Pages** (built using Astro + TypeScript).
* **Backend Automation:** Hosted on **Cloudflare Workers** with **Cron Triggers** (`*/30 * * * *`).
* **Database:** **Cloudflare D1** SQLite database bound as `env.DB`.
* **AI Model:** **Groq Cloud** using `llama-3.1-8b-instant`.

---

## Deployment Steps

### 1. Create Cloudflare D1 Database
```bash
npx wrangler d1 create 9jabeacon-d1
```
Copy the `database_id` generated by Wrangler and paste it into `workers/wrangler.toml`.

### 2. Apply Database Schema Migrations
```bash
npx wrangler d1 execute 9jabeacon-d1 --file=../migrations/0001_initial_schema.sql
```

### 3. Set Cloudflare Secrets
```bash
cd workers
npx wrangler secret put GROQ_API_KEY
npx wrangler secret put ADMIN_SECRET
```

### 4. Deploy the Worker
```bash
cd workers
npx wrangler deploy
```

The worker will automatically trigger on your configured cron schedule (`*/30 * * * *`) and can also receive manual sync calls at `POST https://<your-worker-subdomain>.workers.dev/api/cron/trigger`.
