# News platform

Astro + Cloudflare Pages site with editorial automation and optional 3D presenter renders.

## Stack

- Astro (SSR on Cloudflare)
- D1 for content
- GitHub Actions for scheduled jobs and presenter renders

## Local

```bash
npm install
npm run dev
```

Secrets and deploy tokens belong in **GitHub Secrets** / **Cloudflare environment variables** only — never in this repository.

## Presenter render

Manual workflow: **Presenter Render** (Actions tab).
